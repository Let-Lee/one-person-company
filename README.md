# 一个人的公司

你定目标，AI 团队负责执行。

从零岗位开始，按需创建总经理和员工，交代任务，查看进度与成果。蓝紫配色，支持亮色、暗色与跟随系统；岗位人物有状态动效，办公室用线路展示交接。

## 在 Mac 上开始

准备好 **Node.js 20 或以上版本**，以及已安装、打开并登录的 **Codex 桌面版**。程序没有第三方运行依赖，不需要 `npm install`。缺少 Node.js 时，可先通过 Homebrew 安装：

```sh
brew install node@24
```

在终端运行一键安装：

```sh
curl -fsSL --connect-timeout 10 --max-time 60 https://raw.githubusercontent.com/Let-Lee/one-person-company/main/install.sh | bash
```

安装脚本会使用已有的终端代理；终端未配置时会读取 macOS 已启用的 HTTPS 代理，只用于本次下载，不修改系统设置。下载遇到网络错误时会明确报错，可检查网络后重试。

它会下载本项目、安装到 `~/Applications/OnePersonCompany` 并打开本机页面。以后双击该目录的 **启动公司.command**；结束时双击 **停止公司.command**。更新可重新运行安装命令，数据单独保存在 `data/` 中。

也可以下载仓库 ZIP，解压后双击 **启动.command**。首次运行从空白公司开始，按照全屏引导命名公司、连接 Codex、创建经理和员工；不会导入作者的团队或自动运行示例任务。

页面默认在 `http://127.0.0.1:4318/`。端口已被其他实例占用时，会提示选择其他端口，不会擅自停止其他程序。

## 选择工作方式

|  | 独立 AI 团队 | Codex 桌面聊天 |
| --- | --- | --- |
| 适合 | 在这里组建经理和员工，管理完整任务流程 | 沿用你已经在 Codex 打开的一个聊天 |
| 如何连接 | 按引导创建岗位与固定 Codex 会话 | 引导第二步展开桌面聊天入口，或进入连接设置，选择本机聊天并保存 |
| 执行位置 | 本程序启动的独立 Codex App Server | 你选择的原桌面聊天 |
| 页面能力 | 经理派单、员工执行、Skill、审批、暂停与续办、交付与验收、用量与交接 | 发送任务到原聊天，接收执行进度与回复，保留本页消息记录 |
| 工具范围 | 文件、命令与代码任务；默认不接入桌面电脑控制、图像生成和微信工具 | 继承原聊天的工具、模型与权限；不承诺每个账号拥有全部工具 |
| 团队与控制 | 在本页面管理独立岗位、任务与审批 | 其他桌面成员、审批和停止续办仍在 Codex 中管理 |

桌面连接不需要作者的公司目录或固定聊天 ID。你从本机列表中选择，或手动填写自己的聊天 ID；本机列表只返回标题等元数据，不加载聊天正文。只有实际连接到当前桌面持有端，页面才显示连接成功。连接检查不会发送模型任务。

连接成功后点击“使用桌面模式”，即可直接进入原聊天，无须先创建独立岗位。也可以在连接设置切回“独立团队”，已有数据继续保留。选择聊天不会自动把它变成某个组织的经理，也不会改变它原有的权限。

## 日常怎么用

1. **交代目标**：告诉经理要做什么、可以修改哪里、希望交付什么。
2. **查看进度**：任务页看执行，岗位协作页看分工与回报。
3. **处理审批**：需要你确认的操作会集中显示。
4. **检查成果**：查看实际动作、文件和结果，再决定验收或补充要求。

每位独立员工都有固定对话；经理在自己的团队范围内派单。岗位的技能随任务提供，并保留实际发现与使用记录。执行中可以追加指令、暂停、停止或明确续办。费用未知时不估算金额，模型说“完成”与观察到实际动作分开显示。

首次打开页面、保存设置和创建空会话不会自动执行模型任务。实际任务使用你自己的 Codex 账号及配置。

## 检查与管理

双击 **检查.command** 可检查 Node.js、Codex 程序和桌面入口。也可以在源码目录运行：

```sh
node scripts/manage.mjs doctor
node scripts/manage.mjs start --open
node scripts/manage.mjs status
node scripts/manage.mjs stop
```

指定其他端口：

```sh
PORT=4320 node scripts/manage.mjs start --open
PORT=4320 node scripts/manage.mjs stop
```

`npm start` 为前台运行方式，关闭该进程就停止服务。双击启动器使用后台方式，关闭终端窗口后仍可使用页面。

## 数据与配置

- 下载 ZIP 或克隆源码运行时，数据默认保存在项目的 `.data/` 中；一键安装使用安装目录下独立的 `data/`。
- 岗位、任务、聊天连接与配置属于本机数据。备份该数据目录即可；不应提交到 GitHub。
- 新公司不读取任何作者的通讯录、画像、账单、聊天或运行记录。源码发布不包含 `.data/`、`.runtime/`、账号凭据或绑定后的聊天 ID。
- 服务只监听 `127.0.0.1`，写操作要求本机同源请求。本项目不会把本机控制接口开放到公网。
- 运行只使用所选工作目录；选择已有文件夹时不覆盖其中的 `AGENTS.md`。
- 高级变量和连接排查见 [配置说明](docs/configuration.md) 与 [桌面连接说明](docs/desktop-connection.md)。

## 支持与已验证范围

一键安装与启动器面向 **macOS**。本次验证环境为 macOS 27.2、Node.js 24.21.0、Codex CLI 0.162.1、Codex 桌面版 26.1007.71326（构建 20398）。Linux 与 Windows 尚未做实际部署验证。

独立团队使用 Codex App Server。桌面聊天使用当前安装版本的本机 follower 协议；这不是稳定公开 API，桌面版升级后可能需要适配。版本不兼容时会显示连接错误，不会改用独立会话冒充桌面连接。

`npm test` 运行隔离的回归检查，使用临时目录和协议替身，不读取作者的工作目录或触发真实模型任务。测试通过不等于你的账号、网络或工具已就绪，仍需在页面完成实际连接检查。

## 源码与许可

原生 Node.js ES 模块与 HTML/CSS/JavaScript，无第三方运行依赖。`src/` 是本机服务与运行连接，`public/` 是界面，`scripts/` 是安装和管理入口，`tests/` 是隔离测试。
