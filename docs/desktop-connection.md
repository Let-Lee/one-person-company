# 连接自己的 Codex 桌面聊天

1. 打开并登录 Codex 桌面版，打开你希望连接的聊天。
2. 在公司引导第二步展开“想沿用 Codex 桌面聊天？”，或进入“连接设置”。
3. 点击“从本机选择聊天”，选择目标；也可以直接填写聊天 ID。选择列表只读取本机元数据，不加载聊天正文或创建新聊天。
4. 保存并检查连接。显示“桌面聊天已连接”后，点击“使用桌面模式”。
5. 交代任务后，消息在同一个 Codex 桌面聊天中执行，回复与进度返回页面。

连接使用本机 follower，不接管桌面持有端。发送目标由你保存的设置决定，消息接口不接受临时目标或发送者身份覆盖。相同请求 ID 不重复发送；提交状态未知时保留记录，先核对原聊天，不自动重发。正在执行或等待核实的消息不能解除绑定或改接其他聊天。

本页只保存通过本页发送的消息和对应回复；不会把订阅中的其他聊天历史持久化。解除绑定仅断开自己的订阅，不删除 Codex 聊天。其他桌面岗位和审批仍由 Codex 管理；本机绑定也不授予组织身份。

默认入口为 `~/.codex/ipc/ipc.sock`。选择了其他 Codex 配置目录时，可通过“更多设置”明确填写入口的完整路径。程序检查目录和套接字的所有者及权限，不接受远程 TCP 地址。

如果连接失败，先确认桌面版已打开、目标聊天在本机可用，再点击“重新检查”。本连接实测版本为 Codex 桌面版 26.1007.71326（构建 20398），采用 initialize v0、owner-discovery v1、start-turn v2、stream-state v11 的本机协议。这是根据当前安装验证的兼容实现，不是稳定公开 API；更新后若协议变化，需要重新适配。

独立 App Server 是另一个运行进程，不拥有原桌面聊天的全部内置工具。桌面连接失败时不会用新建独立会话代替它并显示成功。
