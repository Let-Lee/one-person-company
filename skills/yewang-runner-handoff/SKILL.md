# 任务结果回传

这个 Skill 只规定本轮结束时如何把结果交回公司，不改变派单内容或权限。

1. 先完成派单。只把本轮实际执行过的命令、实际改动的文件和实际读到的资料当作结果。
2. 结束前自查：回复里提到的每个文件改动，都应能在本轮命令或文件修改里找到；找不到就写成“未完成”。
3. 最终回复用下面四行，每行一句话，没有内容写“无”：

```text
回传｜结果：……
回传｜实际动作：……（文件路径或命令）
回传｜未完成：……
回传｜需要决定：……
```

不要编造岗位身份、聊天ID或交接凭据；公司页面会记录派单方和回传时间。
